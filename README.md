# NAKAMA PLAY LAB

「仲間」をテーマにした、日本語のプレイアブルモック。Next.js / TypeScript / Tailwind CSS、1人＋ルールベースNPC、バックエンド・外部AI API不要。

## 起動

Node.js 22以降（検証環境：24.19.0）で実行します。

```sh
npm ci --cache /tmp/nakama-npm-cache
npm run dev
```

ブラウザで http://localhost:3000 を開いてください。5つのカードからゲームを選び、ルールを読んで開始します。

```sh
npm test
npm run typecheck
npm run build
npm start
```

## 遊べるもの

- ロストリンク：8人の3属性を調べ、唯一の同属性ペアを推理。全体観察が効率的。
- シンクロエージェント：NPCの秘密の3手周期を見抜き、自分の任務得点3点で指名。任務と隠密で監視警戒を管理。
- バディダンジョン：探索者と守護者を協調操作する3ステージ。鍵＋圧力板＋出口を同時に満たす。
- エレメントリンク：同属性の相手を観察・合流して合体技を発動。敵の大攻撃を防御。
- 仲間チェーン：6人の両隣のヒントを集め、カードを2枚ずつ選んで秘密の輪を復元。

結果で評価を保存し、トップ右上の「プレイ評価」で平均・件数・再プレイ希望率を比較できます。評価はこのブラウザのlocalStorageのみ。サーバー送信はしません。

## 設計・検証

[事前ルール設計](docs/RULES.md)に判断・情報・NPC・勝敗・上達要素を整理。

`lib/game.ts` の `create` と純粋な `transition` がUIと独立したゲームエンジン。seedで配役を再現し、状態をコピーして更新します。`Action.actor` と操作主体チェックを用意。将来の2人プレイではホスト側で状態を保持し、参加者別の公開情報ビューとターン所有権を追加します。現時点で通信マルチプレイは未実装です。秘密はローカルモック内にあり、不正閲覧対策のある製品版ではありません。

開発サーバーだけ「開発モード」でNPCの秘密、選択理由、正解、全状態を表示。通常表示と本番ビルドにはデバッグパネルを出しません。

自動テストは5ゲーム×3seedで勝利・リトライを検証。ロストリンク・シンクロ・バトルは公開情報から推理。ダンジョンは3ステージの全状態をBFS探索して得た手順を実行し、制限内のクリアを検証します。敗北・操作主体・状態の非破壊更新も検証。

現在はゲーム性比較用の小規模モックです。ダンジョンは固定3ステージ、他の配役はシャッフル。時間制限の代わりに手数制限を使います。
